# Connect the Formial dashboard to n8n

There are only two values to create in n8n. Everything else belongs in the dashboard `.env` and is generated by the setup command.

## 1. Import the correct workflow

In n8n, choose **Import from File** and select:

`integration/formial-dashboard.n8n.json` in your repository checkout.

Import it as a new inactive workflow. Its name is **Formial | Dashboard API | Gemini + Nano Banana**. Do not use the older workflow that starts with an n8n Form Trigger.

## 2. Copy the Production Webhook URL

Open **Dashboard Webhook** and copy its **Production URL**. It contains `/webhook/formial-dashboard`. Do not copy a URL containing `/webhook-test/`.

## 3. Configure the dashboard once

In PowerShell:

```powershell
cd path\to\n8n-dashbaord
npm.cmd run connect:n8n
```

Paste the Production Webhook URL and choose where n8n runs. The command validates the URL, generates secrets, writes `.env`, and prints the exact n8n credential values. For n8n on another server, it asks for the dashboard's public HTTPS URL because n8n must send progress and images back to it.

## 4. Add only these two n8n credentials

### Dashboard Webhook credential

Open **Dashboard Webhook**, create **Header Auth**, and enter the values printed by the setup command:

- Name: `x-formial-secret`
- Value: the generated `N8N_WEBHOOK_SECRET`

### Google credential

Create one **Header Auth** credential:

- Name: `x-goog-api-key`
- Value: the raw company Google AI Studio / Gemini API key, with no `Bearer` prefix

Select this same Google credential in exactly five nodes:

1. Creative Director
2. Generate Candidates
3. Inspect Candidates
4. Repair Candidate
5. Inspect Repair

The Google key never belongs in `.env`, dashboard code, a browser field, or this chat.

## 5. Activate and restart

Activate the n8n workflow. Stop the running dashboard process and restart it:

```powershell
cd path\to\n8n-dashbaord
npm.cmd start
```

Open `http://127.0.0.1:3001`. The top badge must say **N8N CONNECTED**. Start with one 2K candidate and repair disabled in **Brand Settings** for the first paid connection test. After that succeeds, restore 4K, two candidates and one repair.

## Where each value belongs

| Value | Put it here |
| --- | --- |
| n8n Production Webhook URL | Dashboard `.env`; the setup command writes it |
| `x-formial-secret` | Dashboard Webhook Header Auth and dashboard `.env`; the setup command generates it |
| Google AI Studio API key | n8n Google Header Auth only |
| Dashboard public URL | Dashboard `.env`; needed when n8n runs in Docker or remotely |
| Dashboard login password | Dashboard `.env`; generated when exposed beyond localhost |

Do not paste API keys or secrets into normal n8n node fields, workflow notes, the dashboard UI, or source files.
